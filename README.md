# red-how-artifacts

Бенчмарк-стенды и сырые материалы исследований red-how. Каждое
исследование — самодостаточный подкаталог: свой README, методология,
исходники бенчей, сырые прогоны.

## Каталог

| исследование | что внутри | статья |
|---|---|---|
| [`serde/`](serde/) | стоимость сериализации/десериализации: Rust + Go, побайтово идентичный пейлоад, три кейса (CRUD, bigdoc, ETL-поток) | готовится |

## Как добавить новое исследование

1. Каталог `<topic>/`: `README.md` (что меряем, quick start),
   `methodology.md` (протокол, гипотезы, ограничения), исходники бенчей,
   `results/` — сырые прогоны без ретуши.
2. Данные, которые можно сгенерировать, не коммитим: в репозитории —
   генератор и гитигнор.
3. Байт-идентичность между языками enforced тестами, не словами.
